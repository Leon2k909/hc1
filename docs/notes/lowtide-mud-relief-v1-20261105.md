# Lowtide mud-bank relief — installed review trial, 2026-11-05

The user requested another slight terrain rise where it makes sense. A narrow section of exposed
tidal mud on the east bank, plan E 180..228 and N 420..660, now has a shallow silt crown of at most
2 inches (5.08 cm). The footprint excludes the low-water channel, stair landings, barge and mooring
piles. All four boundaries taper back to the original surface. The original bed already has small
visual ripples; this change preserves those and adds a small local rise rather than flattening them.

`Tools/lowtide_mud_relief.py` extracts 48 triangles from the installed `lowtide_fleet.obj`, interpolates
their exact positions, normals and UVs, then subdivides them into 768 raised triangles. The source
Fleet mesh is never rewritten. The matching dirt collider uses the same mesh. Total surface slope,
including the original ripples, is below 10 degrees. Geometry checks require the exact expected
source layout, matching bank area and positive winding.

The new asset is `models/maps/lowtide/mud-relief-v1/mud_bank_relief.vmdl`. It compiled and loaded
without an error model. Native scene tools installed and saved one `Mud bank relief - REVIEW TRIAL`
object, ID `bb209960-3faf-4aac-846a-a624ff5411eb`, with a renderer and static ModelCollider.
`output/lowtide/mud-relief-v1/` contains the pre-install scene backup, matched native before/after
images, geometry report, object receipt and runtime check. This is a reversible trial, not a map
generator rebuild. No AI/navigation sweep or performance benchmark has been run. No Git staging,
commit or push was performed; earlier lawn trials remain unchanged.

During review the user asked about a brown fragment in the bank. That object is present in the
before capture: it belongs to existing tidal debris, with fired-clay fragments generated by
`lowtide_marine.banks` and `lowtide_banks.cobble(brick=True)`. It was identified, not changed.
