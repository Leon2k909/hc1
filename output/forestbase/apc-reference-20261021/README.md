# FB / 041 APC — reference reconstruction

The parked 8-wheel APC was visually rebuilt from the first image supplied on 2026-10-21. Its original hull silhouette is retained, with a replacement faceted turret, open muzzle brake, commander optics, angular fenders, shoulder tire treads, louvers, individual bolts, latches, tool shafts and shovel blade, stowage rack, cans, field pouches, roof handles, reflectors and weathered unit markings.

Only the APC inside yard.obj changed. The source triangle comparison checks every modified triangle lies within this vehicle, and verifies every other triangle and every authored physics shape is unchanged. Placement, bounds of the cover and map lighting were retained. Source generators: Tools/forestbase_apc.py and the APC-only hook in Tools/forestbase_map.py. The final model adds 14,030 visual triangles to the yard chunk and no scene objects, lights or frame callbacks. A complete-match FPS comparison has not been performed.

The armor albedo was generated using the built-in image_gen tool with the supplied image as a material reference. The exact prompt is saved in texture-prompt.txt; the selected source is armor-source.png. Production materials and PBR maps are in Assets/materials/forestbase/apc/. Normal, roughness, utility surface maps and stencils are generated by the APC material script. All production textures have power-of-two dimensions. The final finish uses local coating tint and roughness adjustments; scene exposure is unchanged.

The assets were imported through the native HC1 editor connection. The existing scene was already unsaved before this task; its unsaved state was preserved, without saving unrelated scene edits. Native captures use a disposable scene and leave the user's editor camera unchanged.

See audit.json for geometry/physics checks and integration.json for the native compile result and installed captures.
