# Collider west equipment cabinet: accepted

Created and accepted 2026-10-29 after the user accepted the equipment case. The user selected this cabinet with “ye new one is better, do another”. The reviewed cabinet is now installed in Collider's source mesh. No editor launch, connection or scene interaction was used.

The actual west cabinet is at plan `(-430,80,0)`. Its existing 276 render triangles are a rectangular body and repeated blank equipment panels/status blocks. `build.py` copies those installed positions, UVs and normals directly; the old body is not reconstructed from the newer, different generator draft. A pressure gauge was initially considered, but it exists only in an uninstalled generator draft and was discarded rather than presented as an in-game baseline.

The proposed cabinet uses the fabricated equipment-bay style authored for the east stair rack, fitted to the existing west cover envelope. It adds recessed varied-height equipment, open louvres, separate frame/gasket returns, panel hardware, cage-nut holes, individual status lamps, rear fan cartridges and levelling feet. Existing local Collider materials are reused unchanged. Both standalone variants have the same 48 x 60 x 138 inch collision box and exact same physics bytes; the tall original west silhouette remains unchanged in this proposal.

Accepted review files: `Assets/models/props/collider/west-cabinet-trial-v1/after.{obj,mtl,vmdl}`. The unused old standalone resources were removed from Assets; rollback copies remain in `output/collider-cabinet-accepted-20261029/retired-before-resources/`. Evidence: `output/asset-improvement-20261029/west-cabinet/`. Export validation checks winding, degeneracy, finite UVs/normals, material paths, protected accepted sources and collision equality. Before: 276 triangles; after: 17,044 triangles. Engine compilation, LOD and performance acceptance remain pending.

Images are matched Blender Cycles renders of the actual exported OBJs, not engine screenshots. Scale, camera, lighting, sample count and exposure are identical. `install_accepted.py` removed exactly the 276 old cabinet triangles and inserted the 17,044 reviewed triangles. Every other face line and original attribute table was retained. The packed detail mesh now has 188,636 triangles. Its MTL, ModelDoc physics and the saved scene are byte identical; the previously accepted case is preserved. `Tools/collider_west_cabinet.py` and the west branch of `collider_map.detail` reproduce the accepted geometry and original collision box. The primary stage was synchronized only after its before hash matched. Installation and scope checks are in `installed.json` and `output/collider-cabinet-accepted-20261029/verification.json`.
