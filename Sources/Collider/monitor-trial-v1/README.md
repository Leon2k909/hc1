# Collider control-room monitor: accepted

Created and accepted 2026-10-29 after the user accepted the west equipment cabinet and asked for another asset. The user selected the monitor with “ye new one is better do another”. The exact reviewed monitor is installed in Collider's source assets. This work uses source files and offline rendering without launching or connecting to s&box.

The actual baseline is the wall monitor at plan `(1880,-190,381)`, facing west, generated by `collider_map.monitor(...,112,66,0)`. `audit.py` and `build.py` match all 26 of its installed triangles in `collider_structure.obj`, then copy their positions, UVs and normals. The before image therefore shows saved map geometry rather than a reconstructed approximation. The monitor's local bottom is world z345.5 inches.

The proposal retains the 112 x 66 inch active display size and existing atlas quadrant. A shaped graphite casing, chamfered edges, recessed screen/gasket, physical controls, small indicator and printed identification replace the basic box and luminous bar. Split rear covers contain open cooling vents with an opaque internal display backing. A folded wall plate, two pivot arms, fixings, connector and power cable give the display a physical mounting assembly. The cable's service loop terminates through a gland in a sealed wall junction box. The mount and junction box reach the existing wall 20 inches behind the original face. Both variants retain zero authored collision shapes.

Accepted resources: `Assets/models/props/collider/monitor-trial-v1/after.{obj,mtl,vmdl}`. The unused standalone `before` resources were retired outside Assets to `output/collider-monitor-accepted-20261029/retired-before-resources/`. The seven private materials and label texture are under `Assets/materials/collider/monitor-trial-v1/`; the original screen material/texture is reused unchanged. Geometry counts and review SHA256 records are in `candidate.json`. Installation replaced exactly 26 old triangles with the reviewed 6,088 at the same placement. The packed structure now has 214,663 triangles.

`verify.py` checks finite positions/UVs/normals, winding, nondegenerate triangles, material/texture references, the existing atlas mapping and protected structure/detail/scene hashes. The exact original baseline audit is in `output/asset-improvement-20261029/monitor/baseline-audit.json`.

`prepare_render.py` produces a Blender script using the established actual-OBJ renderer. Matched front and rear views use identical scale, camera, lighting, samples and exposure. Images and `render-report.json` are in `output/asset-improvement-20261029/monitor/`. These are offline renders, not native engine screenshots. Engine material/model compilation, native appearance, LOD and performance validation remain pending.

`install_accepted.py` records the three changed structure model source files and preserves every unrelated original face line/attribute table. The saved scene, full ModelDoc physics suffix and all detail mesh sources containing the earlier accepted case/cabinet remain unchanged. Seven private material bindings were added without changing previous bindings. Only this reviewed monitor instance changes. `Tools/collider_monitor.py` and the selected branch in `collider_map.monitor` reproduce the exact mesh/UVs/normals and material remaps with no authored collision. Primary staged sources were synchronized only when their before hashes matched. `installed.json`, `verify_accepted.py` and `output/collider-monitor-accepted-20261029/verification.json` retain the acceptance and scope evidence.
