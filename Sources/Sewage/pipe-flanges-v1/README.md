# Sewage pipe flange review

Six additive bolted flange assemblies on the three west-wall utility runs.
Each uses two bevelled rings, an exposed gasket band, eight through bolts,
washers and hex heads. The approved pipe material and original mesh are preserved.

Staged geometry: 35,712 triangles, render only, reuses the crane steel and dark
materials. Imported model: `models/maps/sewage/pipe-flanges-v1/flanges.vmdl`.
Approved and installed in Sewage as `Waterworks bolted flanges` on 2026-11-04.

Matching native renders: `output/sewage/pipe-flanges-v1/` and its `close/` folder.
The capture creates and destroys an isolated scene without switching editor tabs.
`install.cs.txt` adds one named object in Sewage
and saves only that scene, with no switch of the active scene.
