# Veridant concrete: Quixel Megascans comparison

Preview only. The saved scene, parent map models and original concrete material
remain unchanged. A temporary isolated editor scene uses material-slot overrides
and is destroyed after each render; the active Ridgeback document is preserved.

Source: Quixel Megascans Smooth Concrete, `sdijbcwb`, downloaded from
https://www.fab.com/listings/68db59f6-f151-473b-aa47-48e64f47d8c3
on 2026-11-05 after explicit user approval to accept the Fab EULA.
`provenance.json` records source and archive/file hashes. The downloaded 2K base
colour, normal and roughness maps are copied unchanged to the isolated trial
material folder. The 2x2 metre scan repeats 2.4384 times per existing 192-inch UV
tile. No displacement, colour correction or invented scan detail is applied.

Matched before/after images:
`output/veridant/quality/megascans-concrete-trial-20261105/`.
Native import, compile and capture receipts and final validation:
`output/veridant/megascans-concrete-trial-20261105/`.

Assessment: the scanned surface has more texture but is browner and rougher than
the existing fair-faced panel concrete. It also lacks that texture's form joints
and tie holes. This is not a clear improvement for Veridant's modern architecture;
retain the original unless the user chooses the trial.
