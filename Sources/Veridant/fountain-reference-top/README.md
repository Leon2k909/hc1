# Veridant fountain reference crown

The reclining lion was reconstructed locally with [TripoSG](https://huggingface.co/VAST-AI/TripoSG) from an isolated view of the fountain prototype. `lion-source.png` is the isolated reference and `lion.glb` is the untextured reconstruction.

`Tools/veridant_fountain_reference_top.py` takes the GLB as its argument and builds the game model with the opposed lions, bronze plinths, and carved limestone pier. The installed model is `models/props/shared/veridant_fountain_reference_top/crown.vmdl`. The preceding sculpt is available at `models/props/shared/veridant_fountain_sculpture_v4/sculpture.vmdl`.
