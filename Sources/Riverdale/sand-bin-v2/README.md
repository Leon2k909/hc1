# Riverdale sand bin — realism revision

Refines the preceding staged model after the user said it still needed realism. The formed body, fitted lid, hardware, footprint and original SAND label remain. Curved surfaces now have per-vertex normals derived from their neighbouring faces, removing visible corner faceting. Dedicated object-space PBR maps replace the uniform yellow finish: muted aged yellow plastic, fine moulded grain, scattered shallow scratches, irregular fading, roughness variation and restrained contact dirt at the body's foot. The lid has its own mapping. This is plastic, with zero metalness; no rust or exposed-metal scratches are painted onto it. No lighting is baked into the maps.

`model.py` and `surfaces.py` generate the editable model and deterministic maps; `setup.py` derives this revision from the preserved v1 source. `build.py` stages 16 files and preserves the original 38-face exact-match removal in a private yard base. All live map sources, collision and scene remain unchanged. Materials are scoped to this candidate. `prepare_review.py` changes the native capture to compare the preceding v1 proposal against v2 using the same private base. Run it after the builder and before `review.py`.

Actual offline Riverdale play checks use matching cameras, gameplay effects, locked exposure and 180 ordinary streaming frames per view. No capture lights or forced texture residency. `verify.py` checks original source guards, the private base, matching original records, native map/player/error-model evidence and editor restoration, then composes before/after images in `output/riverdale/sand-bin-v2/`. BEFORE is the preceding improved proposal; AFTER is this realism revision. Staged, not installed.
